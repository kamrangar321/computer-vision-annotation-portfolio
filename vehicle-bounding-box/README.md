# Vehicle Bounding Box Annotation

## Project Overview

This project demonstrates manual vehicle bounding box annotation using CVAT for object detection and computer vision dataset preparation.

## Annotation Details

- Tool: CVAT
- Annotation Method: Bounding Box
- Label: Car
- Task: Vehicle Detection / Object Detection
- Annotation: Manual

## My Work

I manually created bounding boxes around vehicles in road and traffic images. I focused on accurate box placement, consistent labeling, and maintaining annotation quality across frames.

The project includes vehicles at different distances, sizes, and positions within the scene.

- Bounding Box Annotation
- Vehicle Annotation
- Object Detection
- CVAT
- Data Labeling
- Computer Vision
- Annotation Quality Control
- Dataset Preparation
