# Medical Image Lung Segmentation

## Project Overview

This project demonstrates manual lung segmentation on chest X-ray images using CVAT.

## Annotation Details

- Tool: CVAT
- Annotation Method: Polygon Segmentation
- Labels: Left Lung and Right Lung
- Image Type: Chest X-ray
- Task: Medical Image Segmentation

## My Work

I manually created polygon annotations around the visible lung regions in chest X-ray images. I focused on following the lung boundaries carefully and maintaining consistent annotation across images.
