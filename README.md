# Computer Vision Annotation Portfolio

Hi, I'm Kamran Alam.

This repository showcases my hands-on data annotation projects created using CVAT for computer vision and AI dataset preparation.

## 📌 Portfolio Projects

### 🩻 1. Medical Image Lung Segmentation
Manual polygon segmentation of left and right lung regions on chest X-ray images.

**Annotation Type:** Polygon / Image Segmentation  
**Tool:** CVAT  
**Labels:** Left Lung, Right Lung

### 🧍 2. Human Pose Keypoint Annotation
Manual human body keypoint and skeleton annotation for human pose estimation.

**Annotation Type:** Keypoints / Skeleton  
**Tool:** CVAT  
**Label:** Person

### 🚗 3. Vehicle Bounding Box Annotation
Manual bounding-box annotation of vehicles in road/traffic images for object detection.

**Annotation Type:** Bounding Box  
**Tool:** CVAT  
**Label:** Car
