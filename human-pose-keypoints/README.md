
# Human Pose Keypoint Annotation

## Project Overview

This project demonstrates manual human pose keypoint and skeleton annotation using CVAT for computer vision dataset preparation.

## Annotation Details

- Tool: CVAT
- Annotation Method: Keypoints / Skeleton
- Label: Person
- Task: Human Pose Estimation
- Annotation: Manual

## My Work

I manually placed body keypoints on people and connected the relevant points to create human pose skeleton annotations.

The annotations cover different human poses, including standing, running, and exercise positions.
